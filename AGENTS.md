# Sidaps Portfolio development

- The user requires every completed website change to be saved to https://github.com/aliyaamanda591/SIDAPS-PORTFOLIO as well as deployed to the existing website where appropriate.
- Read the latest remote branch before committing; preserve changes and do not force-push without an explicit request.
- Keep account credentials, production databases, personal transactions/backups, `.env`, `.dev.vars`, dependencies, and build artifacts out of Git.
- Each account owns its portfolio. Admin/developer access to account metadata must not grant access to another user's financial records.
- Preserve existing users and data when changing authentication/storage. Never claim an external service is connected until the real configuration has been checked.
